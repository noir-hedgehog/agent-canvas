# 产品边界

AgentCanvas 是人和 Agent 持续共创的本地画布。卡片承载内容，关系表达结构，节点子画布展开细节，讨论请求引用稳定对象与版本。

首版包含独立本地应用与公开浏览器演示。持久化服务为 Node.js 24、Express 和内置 SQLite；React Flow 负责单层画布；MCP 适配器经本地 HTTP 服务读写，不直接修改数据库。

用户与 Agent 共用事务命令，内容与布局分别更新。批注状态与解决/归档状态独立，复制指令不代表 Agent 已收到或正在运行。

公网部署、多人协作、内置 Agent 执行器和真实宿主会话接入均不属于当前发行范围。功能与后续规划见根目录 README 和首次启动的公开示例画布。
