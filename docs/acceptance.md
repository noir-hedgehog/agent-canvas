# v0.1.0 发行验证

验证以此仓库的 GitHub Actions 结果为准，工作流同时构建本地前端与 Pages 演示；浏览器截图随运行记录保存。

- 数据和协议测试：事务回滚、版本冲突、请求去重、撤销、共享任务、层级及删除恢复、归档、授权范围、文件读取和真实 STDIO MCP 读写。
- 示例数据：独立创建的功能导览与路线图，三级导航、共享任务、图卡片、Mermaid、文件和归档示例；首次初始化幂等。
- Pages：独立浏览器存储适配器，无后端凭据，不运行 Agent 或 MCP。自动浏览器测试验证渲染、修改后重载、三级导航、文件及 Mermaid 预览。
- 本地包：预构建前端、源代码运行服务和锁定依赖清单；不包含 Node 运行时及 node_modules，首次启动需要网络。发布流程从解压包安装生产依赖，并验证启动、样例和重启持久化。
- 脱敏：包采用文件白名单；排除 `.agentcanvas`、`.codex`、历史验收材料和个人绝对路径。公开媒体为自行生成的图像和短视频。

协议客户端测试与实际 Agent 客户端接入不同：自动化测试验证真实 MCP 协议，但不等同于该发行包已完成 Codex 桌面端人工联调。macOS / Linux 的包内启动路径分别验证；Windows 启动器提供但未做桌面交互验收。Docker 未发布。
